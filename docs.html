Getting started — API surface

Mounting

createRoot(container) — instantiates a RILLIORoot and calls validateTraversalTree eagerly. Returns { render(value), unmount() }. A container with a live root throws RILLIO_ROOT_OCCUPIED instead of overwriting your DOM silently. 

import { createRoot } from "rillio";

const root = createRoot(document.getElementById("app"));
root.render(value);
root.unmount();

JSX configuration

Point your compiler at Rillio: jsxImportSource: "rillio". Because attributes neutralize to runtime values, all DOM properties/attributes are typechecked — really unknown ones are rejected instead of silently accepted like the React definitions. 

/** @type {import('rillio/jsx-runtime').JSX} */
declare module "rillio" {
  // tsconfig: jsx: ["react-jsx", { jsxImportSource: "rillio" }]
}

Façade modules

rillio/external-store — store executor, resubscribe-free. rillio/dom-family helpers including async resource(). rillio/devtools — flat-index inspector and diagnostic HUD.

Strict typing

Everything above is strict: true under tsc --noEmit. Blocks that compose values keep the alias types the compiler sees, so selectors stay honest without casts.

Architecture

Flat Index is the source of truth

The builder produces a FlatBuilderTier summary — the runtime keeps a FlatIndex where own ids and nextSibling pointers define a DFS order. The DOM is a projection: getNode resolves anchors, and mutations go through validateMoveMany transactions with rollback-on-failure.

Transaction pipeline

Every commit is one transaction: index splices up front, DOM moves follow, each move lands on a validated target. Savepoints (savepoint() / rollbackTo(savepoint)) from the 0.1.x line let a partially-applied batch unwind cleanly.

Ownership & refs

Node IDs are never reused. Ledger-backed owner records survive trees that look identical to the naive eye; focus and ref="owner" semantics do not change when unrelated siblings reorder.

Devtools

rillio/devtools exposes the flat-index inspector plus a diagnostic HUD for transaction churn, giving you a window into the actual committed order rather than a component-tree illusion.

Component lifecycle

The un-memoized rule

A parent update re-renders all children every time — unlike React's default assumptions there is no hidden memoization. Keep state near its owner and selectors near their leaves, because rerenders are cheap but arbitrary work is not.

Verified matrice

tests/component-lifecycle-matrix.test.ts proves the 100-case matrix: fresh mount, rerender key, element-swap, sibling-move, append and removal cases — all with ordered rules, so behavior never regresses silently as the runtime changes.

Compatibility

Hook subset

The compat façade supports the common hooks: useState, useEffect, useMemo, useCallback, useRef — each verified against concrete migration cases.

Explicitly not promised

Context, Suspense, SSR, synthetic-event parity, and the React devtools protocol are not compatibility goals. createPortal / PORTAL_TYPE exist in unreleased work and are changing — treat them accordingly. See docs/COMPATIBILITY.md for the full honesty table.

Rillio 0.1.0 vs React 19.3.0 (flushSync), Preact 11.0.1, Vue 3.5.43 — Chromium 156, macOS arm64 (M1 Pro). ZamUI matches or leads on 5 of 6 scenarios at 2,000 rows. Medians of 27 timings per cell; new mount work keeps landing (2.0 down from 3.1).

  • Keyed diff: numeric old-index array + byte-mask LIS replaces ID→index Maps/Sets; pure same-parent move groups batch into one transaction/undo snapshot.
  • Reverse fast path (reconcileReversedChildren): O(N) linear detection with zero allocations; direct insertBefore, no per-node fragments.
  • Zero-allocation transaction tracking — monotonic startNodeId beats Set<NodeId>.
  • MRU locality caching in NodeRegistry (4-slot node, 2 -slot owner); leaf text fast path in JSX mount.
  • Cycle-pruning: fresh leaves and same-parent moves skip isDescendant ancestry walks.
  • Profiled at 100 μs with npm run profile:browser: mount work concentrates at createNode / insertBefore; reverse at native insertBefore and moveChildren.
